# CryptoTrack

## Description


CryptoTrack permet de consulter, rechercher et organiser 30 cryptomonnaies
provenant d'une **API personnalisée** 


## API utilisée

- **Nom** : API FastAPI personnalisée (CryptoTrack API)
- **URL locale** : http://localhost:8000
- **Documentation** : http://localhost:8000/docs
- **Source des données** : MOCK_DATA.csv (30 cryptomonnaies)



### Backend (FastAPI)
```bash
pip install -r requirements.txt
python main.py
```

### Frontend (React)
```bash
npm install
npm run dev
```
